# ADR-0004: The benchmark shows TBD until a real run produces numbers

## Status

Accepted.

## Context

The project targets a relative improvement of about 26%, but that figure has not been measured. A benchmark page that shows a plausible number before a run would be a fabricated result.

## Decision

- `results/benchmark.md` is generated by `python -m fineforge_train.bench.report`. With no results file, every metric cell reads `TBD`, and the headline reads `Headline: relative improvement = TBD (target ≈ 26%; not yet measured)`.
- Relative improvement is `(tuned - base) / base * 100`. It is computed only from measured values, and it reads `n/a` when the base is 0.
- Each results JSON records the model id, adapter path, eval file SHA-256, sample count, seed and a UTC timestamp, so a run can be reproduced and checked.
- No benchmark numbers appear in the README, DEMO.md or WRITEUP.md.

## Consequences

- Anyone can see that the headline is unmeasured. A reader cannot mistake the target for a result.
- The Colab notebook is the path to a real number. Until someone runs it and commits the results file, the table stays TBD.
