# Benchmark methodology

The benchmark compares the base model with the base model plus the LoRA/QLoRA adapter on the same eval file.

## Reporting rules

- `results/benchmark.md` is generated by `python -m fineforge_train.bench.report`. When no results file exists, every metric cell reads `TBD`, and the headline line reads `Headline: relative improvement = TBD (target ≈ 26%; not yet measured)`.
- Relative improvement is `(tuned - base) / base * 100`. It is computed only from measured numbers and rendered as `n/a` when the base score is 0.
- Every results JSON records the model id, adapter path, eval file SHA-256, sample count, seed, generation parameters and a timestamp, so a run can be reproduced.
- No number appears in the repository unless a run produced it.
